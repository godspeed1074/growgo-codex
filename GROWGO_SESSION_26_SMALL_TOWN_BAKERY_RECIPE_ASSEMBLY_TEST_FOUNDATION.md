## 4. Building Definition

### Visual direction

The building should read as:

- small town
- welcoming
- bright
- display-oriented
- public-facing
- papercut 2.5D compatible
- lightweight and overview-readable

### Functional characteristics

- road-facing small-town commercial frontage
- clear public entrance
- large display window presence
- visible bakery counter/service frontage
- readable sign-led identity
- optional compact outdoor pause zone rather than full cafe seating dependence
- soft landscape edge that does not weaken the shopfront read

## 5. Assembly Plan

### Footprint

- width: `7m-9m`
- depth: `8m-11m`
- lot type: small-town main street, village corner, or neighbourhood retail strip lot

### Frontage orientation

- the primary facade must face the nearest road or active pedestrian edge
- the frontage should align with the current GrowGo north-facing presentation logic for readability in overview and gameplay views

### Entrance location

- entrance should sit on the primary frontage
- preferred placement: off-center to allow a strong display window zone on one side and service frontage balance on the other
- alternate compact placement: centered entry for narrow lots

### Display window placement

- display window belongs on the primary road-facing facade
- preferred placement: dominant customer-facing frontage zone nearest the highest pedestrian read
- the display window should visually outperform general glazing so the bakery reads differently from the cafe

### Service counter placement

- service counter frontage should sit behind or adjacent to the display window zone
- counter visibility should be readable from the entry side and gameplay camera
- counter placement must not block circulation from the door

### Awning placement

- awning may reuse the hospitality frontage logic where width and facade rhythm are compatible
- bakery use should prefer shallower commercial weather cover over deep social seating projection
- the awning must preserve the sign band and display window visibility

### Outdoor seating placement

- outdoor seating is optional, not mandatory
- if used, it should sit as a compact frontage pause area rather than the primary identity driver
- seating must never overpower the bakery storefront or display window

### Signage location

- primary sign should mount on the road-facing facade in the main sign band
- secondary hanging sign may be used where pedestrian corner visibility matters
- signage should reinforce bakery identity more directly than the current cafe sign family

### Landscaping

- planting should soften frontage corners or side edges only
- path access and display readability must remain unobstructed
- tree placement should remain outside the main bakery sign and display cone
