# Wizard of Oz card sources

Owner rule recorded 19 September 2026.

Wizard of Oz cards may be awarded from these sources:

- Movie theatres
- Card packs
- Random rewards
- Grain silos with murals

This records eligible sources only. It does not yet define drop rates, card rarities, duplicate handling, geographic coverage, or whether each source has a daily limit. Those rules must be set before live implementation.
