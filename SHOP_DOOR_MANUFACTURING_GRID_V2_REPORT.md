# Door Manufacturing V2 — Shared Reference Grid

**Status: PASS — 2D preflight only. No Blender work was performed.**

The V2 draft measures the door from eleven shared X guides and sixteen shared Z guides in the authoritative 300×350 close-reference crop. Upper clipped guide positions are projected into the same grid only from the wide reference using common casing/slab anchors.

## What the coordinated grid found

| Component | V1 normalized | V2 normalized | Largest delta |
| --- | ---: | ---: | ---: |
| Slab width | 0.761 | 0.683 | -10.3% |
| Main glass width | 0.501 | 0.457 | -8.8% |
| Casing width | 0.123 | 0.140 | +13.8% |
| Lower panel width | 0.498 | 0.457 | -8.2% |
| Threshold width / height | 0.858 / 0.090 | 0.683 / 0.140 | -20.4% / +55.6% |
| Transom width / height | 0.712 / 0.150 | 0.683 / 0.189 | -4.1% / +26.0% |

The largest V1 discrepancy is **threshold height: +55.6%**. The V1 glass frame is also 19.3% too wide, while the V1 slab is 10.3% too wide.

## Vision decision

The shared-grid preflight aligns the slab, glass, casing, lower panel, mail slot, hardware axis, threshold, and upper transom/head bounds as one measured architectural system. The **2D architectural same-door gate passes**. V1 is superseded but preserved for history; V2 is authorized for one clean, isolated Blender fabrication.

No Blender door, shop, Atlas, or eucalyptus asset changed.
