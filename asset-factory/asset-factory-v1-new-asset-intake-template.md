## Intake Notes

- Asset name should describe the permanent reusable asset, not a scene.
- Family should match the target production family or explicitly note that a new family foundation is required.
- Purpose should explain how Atlas or GrowGo will use the asset.
- Biome/theme should identify environment fit, palette context, and world tone.
- Expected LODs should usually be `LOD_CLOSE`, `LOD_GAMEPLAY`, and `LOD_MAP`.
- Performance budget should describe target geometry, material, and mobile-first expectations.
- Dependencies should list reusable modules or state `none`.
- Visual references should describe art direction, silhouette intent, and any human-provided references.
- Approval criteria should define what a human reviewer must explicitly confirm.
