# Asset Factory v1 Revision Workflow

Date: 2026-07-29  
Status: Permanent revision workflow

## Standard Revision Path

v001 creation  
↓  
visual review  
↓  
v002+ revision  
↓  
protected history  
↓  
promotion

## Rules

- `v001` starts as the first production-ready baseline.
- Visual review decides whether `v001` is accepted as-is or whether a versioned revision lane is required.
- `v002+` revisions must preserve asset identity while changing only the targeted geometry or presentation issues.
- Older approved revisions remain historical and protected.
- Promotion changes the active development revision only after source, export, validation, and visual evidence all agree.

## Expected Revision Records

- revision specification
- versioned authoring setup
- versioned source verification
- versioned export manifest
- versioned export validation
- versioned visual approval record
- versioned registration or catalog records
- versioned promotion record
